# D2R Terror Zone Overlay (暗黑2重制版 恐惧地带悬浮窗)

一款轻量、优雅的《暗黑破坏神 II：重制版》（Diablo II: Resurrected）恐惧地带（Terror Zone）桌面悬浮提示工具。

无需进入游戏或频繁切屏网页，在桌面上即可直观查看当前恐惧区域及下一次轮换倒计时。

---

## ✨ 功能特性

- 🕒 **实时轮换提醒**：实时显示当前恐惧地带与下一轮预告区域。
- ⏳ **精确倒计时**：清晰的每小时轮换倒计时，不错过关键区域。
- 🌐 **多语言本地化**：支持简体中文、繁体中文、英文等多语言显示。
- 🖥️ **桌面悬浮窗设计**：
  - 窗口置顶（Always on Top），方便游戏时边刷边看。
  - 支持拖拽定位、透明度调节，轻巧不挡视线。
- 🛡️ **安全绿色**：纯桌面工具，**不读取游戏内存、不注入进程、不修改游戏客户端文件**，安全放心。

---

## 🚀 快速上手

### 直接运行（玩家推荐）
1. 在 [Releases](../../releases) 页面下载最新版本的压缩包。
2. 解压后直接运行 `D2RTerrorZone.exe` 即可使用。

### 源码编译（开发者）
- 开发环境：Windows 10/11，Visual Studio 2022 或更高版本 / .NET SDK
- 运行框架：.NET 6.0 / .NET Framework / WPF

```bash
git clone https://github.com/wSirius177/D2RTerrorZonetool.git
cd D2RTerrorZonetool
dotnet build
```

---

## 🛠️ 配置与存储

- 配置文件自动保存于用户的 AppData 目录：`%APPDATA%\D2RTerrorZone\settings.json`，不会污染工作目录。
